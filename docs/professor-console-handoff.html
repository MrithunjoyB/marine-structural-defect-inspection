1. Project purpose

StructVision-AI takes one local image and returns ranked visual-anomaly proposals for expert review. Each returned proposal has a binary mask, a mask-derived half-open bounding box, heuristic evidence, and provenance. The current system supports method inspection and research planning; it does not classify structural damage or decide engineering fitness.

Required interpretation: Review proposals only — not confirmed defects or engineering diagnosis.

3. Block diagram

The console and Streamlit clients call the public StructVision facade. The frozen adapter invokes the byte-protected classical modules and returns typed in-memory results. Files are written only by an explicit output path.

4. Input–process–output explanation

Input

The command accepts one PNG, JPEG, or TIFF. It validates encoded size, format agreement, pixel dimensions, bit depth, and colour mode. Alpha-bearing files require an explicit drop or composite policy. The run stores a lossless normalised PNG and records both the source-encoded hash and normalised-copy hash.

Processing

The stable method normalises to BGR, applies the frozen preprocessing configuration, extracts the protected feature families, generates and refines candidate masks, applies contextual scoring, and returns the frozen ranking. The command executes this detector exactly once. Timings are measured fields returned by the API, not fabricated progress values.

Output

The run contains an overlay, tabular CSV, structured JSON, technical summary, one exact binary mask per returned proposal, exposed anomaly evidence, stage records, a console transcript, and a hash manifest. Unexposed internal stage images are explicitly labelled unavailable.

5. Exact Terminal commands

Prepared Mac: direct live command

cd "/path/to/marine-structural-defect-inspection"
source venv/bin/activate
structvision-professor-demo \
  --input "/path/to/demonstration-fixture.png" \
  --output-dir "/path/to/demo-run"

For an alpha-bearing image, add --alpha-handling composite_white. Existing run directories are protected. Use --overwrite only when the exact target may be replaced.

Prepared Mac: one-command launcher

scripts/run_professor_demo.sh \
  --venv "/path/to/marine-structural-defect-inspection/venv" \
  --input "/path/to/demonstration-fixture.png" \
  --output-base "/path/to/presentation-runs" \
  --open

Build and verify the drive bundle

python scripts/build_professor_handoff.py \
  --output "/path/to/StructVision-AI-Professor-Handoff"

python scripts/build_professor_handoff.py \
  --verify "/path/to/StructVision-AI-Professor-Handoff"

9. Demonstration script

  1. State that the screen will show review proposals, not diagnosis.
  2. Show the fixture label: synthetic, excluded from research cohorts, and not real inspection evidence.
  3. Run structvision-professor-demo and point out format, dimensions, colour path, exact method identity, and stable status.
  4. Explain the measured stage timings after the single completed analysis.
  5. Open overlay.png, then proposals.csv, result.json, and one mask.
  6. Show the block diagram and map the stages to source files.
  7. Close with evidence limits, rejected-hybrid status, and the future private-data protocol.

Expected console headings are Input, Format, Dimensions, Colour path, Method, Status, Measured processing stages, Selected proposals, and Generated.

10. Current evidence and limitations

Current comparative evidence is synthetic and development-only. It does not establish performance on marine structures, transfer across cameras or environments, calibrated uncertainty, publication readiness, or deployment readiness. The stable classical method is retained for transparent, local proposal generation—not because global or real-world superiority has been shown.

Live runtime varies with hardware and operating state. Measured stage timings demonstrate execution flow; they are not a benchmark claim.

11. Why the hybrid is rejected

The predeclared protocol allowed at most a 0.02 overall micro-sensitivity loss and also required image-level sensitivity preservation. The hybrid moved micro sensitivity from 0.770833 to 0.750000, a loss of 0.020833, and image sensitivity fell from 0.894737 to 0.868421. Lower false-proposal burden and higher precision/localisation do not override those failed rules. The status therefore remains rejected development candidate; the holdout was not rerun to revise it.

13. Security and privacy

  • Classical analysis is local and offline after dependency installation; no API key, cloud service, telemetry, or paid API is required.
  • The console never installs packages, downloads weights, or writes to a research database.
  • Run manifests store relative file names, not absolute source paths or private environment variables.
  • The drive source ZIP comes from committed Git content using git archive HEAD, not from the multi-gigabyte working directory.
  • Virtual environments, caches, databases, model weights, learned memories, private images, professor data, and historical result stores are prohibited from the bundle.

After the meeting

Retain the immutable drive bundle only under the agreed project retention policy. Delete temporary presentation runs containing any caller-authorised non-fixture image when they are no longer needed, including local copies and trash, and record the deletion if project governance requires it. Do not delete reviewed scientific stores or source history as part of presentation cleanup.

Malformed, oversized, or high-bit-depth inputUse a supported valid uint8 PNG/JPEG/TIFF; do not bypass validation during the meeting.

Missing intermediate imageRead pipeline-stages.json. Unexposed stages are intentionally not fabricated.
Checksum verification failsStop using the copy, recopy from the verified source bundle, and rerun --verify.

15. Questions the professor may ask

Is each proposal a defect?

No. It is a visual anomaly candidate for expert review.

Are the scores probabilities or confidence?

No. Classical values are heuristics, PatchCore values are nearest-normal distances, and hybrid values are fixed linear rank scores.

Why is classical the live default?

It is the stable, frozen, transparent base method, runs locally without learned artifacts, and retains the strongest current sensitivity evidence. That is not a global-superiority claim.

Why not present the hybrid as the improvement?

It failed the predeclared overall and image-level sensitivity-preservation rules, so its status remains rejected.

Did the demonstration retrain or rerun an experiment?

No. It performs one image analysis only. It does not invoke a dataset registry, experiment executor, holdout, or evaluation store.

Where are every internal-stage image and threshold map?

Only artifacts already exposed by the frozen public facade are exported. Unavailable internals are labelled rather than invented or added by changing the detector.

Can I review the source from the drive?

Yes. The source ZIP is made from the exact recorded Git commit, and the source manifest and checksums verify it.

Can I run this on another machine immediately?

Only if compatible Python and platform dependencies are installed. The bundle deliberately contains no virtual environment or unverified platform wheelhouse.

Can it use professor-provided data?

Potentially, after written authority, private intake controls, agreed semantics, group-aware split locking, and a predeclared prospective pilot. No professor data is in this package.

Does it require internet or an API key?

No for the installed base analysis. Initial dependency installation on another machine is a separate platform task.
