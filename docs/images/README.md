# Documentation Images

This directory is reserved for reviewed figures used in repository documentation.

Before adding an image, confirm that it is generated by the project or has documented permission for public redistribution. Do not add externally provided, private, restricted, or unlicensed inspection imagery.

Candidate future figures include:

- a system overview;
- representative feature maps and proposal masks;
- the registered dataset dashboard;
- category-wise and paired comparison outputs;
- the ablation leaderboard; and
- representative success and failure cases.

Figures should identify their experiment scope and avoid implying certified diagnosis.
